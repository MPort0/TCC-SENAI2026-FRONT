1. Coleta de Dados Pessoais

Em Miúdos (TL;DR)

Coletamos dados que você nos fornece (como nome e e-mail) e dados de navegação (como IP e cookies) para fazer o serviço funcionar.

Em conformidade com a LGPD (Lei Geral de Proteção de Dados), coletamos apenas os dados estritamente necessários para a prestação dos nossos serviços:

  • Dados de navegação: Endereço IP, tipo de navegador, páginas visitadas e tempo de permanência.
